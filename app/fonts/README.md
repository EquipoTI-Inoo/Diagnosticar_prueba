# Fuentes autohospedadas

`archivo-800-87.woff2` es una instancia estática (wdth 87.5, wght 800) y un subset latín de
**Archivo**, generados con `scripts/build-fonts.py` a partir de `Archivo-VariableFont_wdth,wght.ttf`.

Inter Tight y JetBrains Mono se sirven con `next/font/google`, que también las autohospeda en el build.
