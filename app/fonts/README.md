# Fuentes autohospedadas

Generadas con `scripts/build-fonts.py` (subset latín + español) a partir de los variables de
github.com/google/fonts:

| Archivo | Origen | Instancia |
|---|---|---|
| `archivo-800-87.woff2` | `ofl/archivo/Archivo[wdth,wght].ttf` | estática wdth 87.5 / wght 800 |
| `intertight-400-500.woff2` | `ofl/intertight/InterTight[wght].ttf` | variable wght 400–500, sin hinting |
| `jetbrains-500.woff2` | `ofl/jetbrainsmono/JetBrainsMono[wght].ttf` | estática wght 500, sin ligaduras ni hinting |
